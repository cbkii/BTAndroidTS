## Why this is included

Android peripheral/server app emulating BLE HID mouse/keyboard. Useful as a compact HOGP example to cross-check service and report-map assumptions.

## Use for

- HOGP peripheral setup
- basic vs advanced mode compatibility
- service discovery expectations

## Caution

Example app. Use only as precedent for expected BLE evidence; not as production host code.
