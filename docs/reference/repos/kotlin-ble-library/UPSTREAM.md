## Why this is included

Modern Kotlin/coroutines BLE wrapper. Useful for Flow/state modelling ideas compatible with BTAndroidTS' Kotlin/Compose direction.

## Use for

- coroutine boundary patterns
- typed BLE state
- structured cancellation

## Caution

Beta/newer library. Do not adopt wholesale for Android 10 TS18 without careful dependency and API29 testing.
