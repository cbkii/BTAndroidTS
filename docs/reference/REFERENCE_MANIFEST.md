## Official/source references

| Reference | URL | Why useful |
|---|---|---|
| Android BluetoothHidDevice API reference | https://developer.android.com/reference/android/bluetooth/BluetoothHidDevice | Primary source for phone-side HID Device lifecycle: registerApp, foreground/registration requirement, sendReport interrupt-channel semantics. |
| Android BluetoothLeScanner API reference | https://developer.android.com/reference/android/bluetooth/le/BluetoothLeScanner | Primary source for BLE scan behaviour, including unfiltered scan screen-off behaviour and Android 10 location permission requirement. |
| Android ScanSettings.Builder API reference | https://developer.android.com/reference/android/bluetooth/le/ScanSettings.Builder | Primary source for setLegacy, setPhy, setReportDelay and low-latency scan mode behaviour. |

| AOSP Bluetooth architecture documentation | https://source.android.com/docs/core/connect/bluetooth | Architecture reference for Android Bluetooth app, Binder/JNI and stack/HAL separation. |
